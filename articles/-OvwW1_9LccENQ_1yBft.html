■ 路上で時計を売っていた少年

1994年12月6日、ギリシャ・アテネに生まれたヤニス・アデトクンボ。両親はナイジェリアからの移民で就労ビザを持たず、一家は不法移民として市民権を得られないまま生活を送った。ヤニスは兄弟とともに路上で時計や眼鏡などを売り、家計を支えることもあった。

ギリシャにもナイジェリアにも居場所がない。無国籍者として育った彼が海外に渡航できるようになったのは、NBAドラフトのわずか2ヶ月前にギリシャ国籍を取得してからのことだった。

そんな境遇から這い上がった男が、のちにNBA史上最高クラスの選手になるとは、誰も想像しなかった。

■ バスケットボールとの出会い

ヤニスがバスケットボールを始めたのは13歳のとき。テレビで見たNBAに魅せられ、近所でプレーしていた若者たちに誘われたのがきっかけだった。

2011年にギリシャのプロチーム・フィラスリティコスBCでプロデビューし、2013年のNBAドラフトでミルウォーキー・バックスから全体15位指名を受け、18歳でNBAの舞台に立った。

■ バックスでの13年間 — 数字で見る、驚異の成長

ルーキーイヤー2013年、当時18歳のヤニスの入団時の体重はわずか89kg。211cmの長身に対してあまりにも線が細く「NBAのフィジカルに耐えられるか」と懸念されることもあった。

しかしそこから彼は、コートでプレーしながら同時に肉体改造を続けた。筋トレと食事管理を徹底し、プロ入り後の数年で体重は110kgを超えるまでバルクアップ。ただ重くなっただけでなく、その巨体のまま驚異的なスピードとアジリティを維持し続けた。肉体の変化がそのままスタッツの変化として現れた。

【年度別スタッツ推移】

2013-14（ルーキー）：6.8得点 / 4.4リバウンド / 1.9アシスト ※体重89kg、全体15位指名

2016-17：22.9得点 / 8.8リバウンド / 5.4アシスト ※最優秀躍進選手賞（MIP）受賞

2018-19：27.7得点 / 12.5リバウンド / 5.9アシスト ※初MVP・バックスをリーグ最多60勝へ

2019-20：29.6得点 / 13.7リバウンド / 5.8アシスト ※MVP連覇・最優秀守備選手賞のダブル受賞

2020-21：28.1得点 / 11.0リバウンド / 5.9アシスト ※NBAチャンピオン・ファイナルMVP

2022-23：31.1得点 / 11.8リバウンド / 5.7アシスト ※55得点・54得点など爆発的スコアリング

2025-26（最終年）：27.6得点 / 9.8リバウンド / 5.4アシスト ※ケガで36試合のみ・FG成功率はキャリアハイの62.4%

ルーキー時代の平均6.8得点だった選手が、10年後には平均30得点超えの怪物に進化した。

【記録が語る、怪物の凄さ】

1シーズン中に得点・リバウンド・アシスト・スティール・ブロックの5部門すべてでリーグトップ20位以内にランクインしたのは、NBA史上ヤニスただ一人。

個人タイトルも圧巻の一言だ。

シーズンMVP：2回（2019、2020）

ファイナルMVP：1回（2021）

最優秀守備選手賞（DPOY）：1回（2020）

最優秀躍進選手賞（MIP）：1回（2017）

オールスターMVP：1回（2021）

オールスター選出：10回

オールNBAチーム選出：9回

オールディフェンシブチーム選出：5回

NBA75周年記念チーム選出

MIP・シーズンMVP・ファイナルMVP・オールスターMVP・最優秀守備選手賞の5冠を総なめにしたのもNBA史上唯一だ。

通算2万1000得点をNBA史上6番目の若さで達成。その上にいるのはレブロン・ジェームズ、ウィルト・チェンバレン、コービー・ブライアント、ケビン・デュラント、マイケル・ジョーダンというスーパースターのみだ。

【2021年NBAファイナル、あの夜】

2021年ファイナル対フェニックス・サンズ戦でヤニスはシリーズ平均35.2得点・13.2リバウンド・5.0アシスト・1.8ブロックをマーク。バックスを4勝2敗で制して50年ぶりの優勝をミルウォーキーにもたらし、ファイナルMVPに輝いた。

第6戦でヤニスが刻んだのは50得点・14リバウンド。バックスのファンなら一生忘れられない夜だろう。

■ 終わりの始まり — バックスとの関係が崩れた瞬間

ヤニスとバックスの関係に最初にヒビが入ったのは、2024-25シーズン終盤のことだった。

ヘッドコーチのドック・リバースが退任を発表。その報を受けたヤニスは「俺はまだ聞いてない。ショックだよ。電話して確認しなきゃ」と戸惑いをあらわにした。指揮官交代の知らせを、本人より先にメディアが知っている——フランチャイズの絶対的エースへの扱いとしては、あまりにも不誠実だった。

そして今シーズン、状況はさらに悪化した。ケガが相次いでわずか36試合の出場に留まったヤニスは、それでもコートに立ち続けようとした。しかしチームスタッフはそれを制止。「ケガを押してでもプレーしたい」という選手と「休ませるべき」というフロントの衝突は、外から見ても明らかな亀裂となった。

2016-17シーズンから続いていたプレーオフ連続出場も途絶え、バックスは東カンファレンス10位に沈んだ。13年間守り続けてきたヤニスのプレーオフ出場記録に、ついて終止符が打たれた瞬間だった。

■ トレード交渉の全貌 — ヒートかセルティックスか

バックスがヤニスのトレードを本格検討し始めたのは今年2月のトレード期限前後のことだった。この時点ですでに報道が明るみに出て、ヤニスとバックスの関係に修復不可能なダメージを与えることになった。

バックスは最終的に交渉相手をヒートとセルティックスの2チームに絞った。

セルティックスは積極的に動いた。2024年のファイナルMVPであるジェイレン・ブラウンと、1巡目指名権2つを含むパッケージを提示。決して安くはないオファーだった。

しかしバックスが選んだのはヒートのパッケージだった。

【トレードの内訳】

ヒート → バックス：タイラー・ヒーロー、ケレル・ウェア、ハイメ・ハケスJr.、カスパラス・ヤクチョニス、2031年・2033年の無保護1巡目指名権、2026年ドラフト全体13位指名権、2030年スワップ権、2033年の2巡目指名権

バックス → ヒート：ヤニス・アデトクンボ、ボビー・ポーティス

なぜセルティックスではなくヒートを選んだのか。答えはシンプルだ。バックスは「再建のためのエース」ではなく「再建のための資産」を必要としていた。ヒートのパッケージには若手4選手と指名権3つが含まれており、長期的な再建により適していると判断した。

新ヘッドコーチにはグリズリーズで若手主体の強豪を作り上げたテイラー・ジェンキンスを迎えることも決定。ヤニス以後のバックスは、時間をかけてチームを作り直す方針だ。

■ マイアミで、新たな伝説が始まる

かつてシャキール・オニール、レブロン・ジェームズ、クリス・ボッシュ、アロンゾ・モーニング、ジミー・バトラーを獲得してきたパット・ライリー球団社長が、またNBAのトップスターをマイアミに連れてきた。

ヒートにとって今シーズンは苦しいシーズンだった。2024-25シーズン途中にエースのジミー・バトラーが契約延長交渉でフロントと衝突して退団し、強豪としてのアイデンティティを失っていた。今シーズンは43勝39敗と辛うじて勝ち越したものの、プレーインどまり。

そこにヤニスが加わる。バム・アデバヨとヤニスという2人のオールディフェンシブ級選手が先発に並ぶフロントコートは、今後のNBAで最強クラスの守備力を誇るコンビになりえる。さらに昨シーズンのヤニスはFG成功率62.4%というキャリアハイを記録しており、フィジカルが戻れば攻撃力も本物だ。

トレード報道直後、ヒートの優勝オッズはリーグ9位（30倍）からリーグ5位（18倍）へ大幅に上昇。東カンファレンスの勢力図を塗り替える一手として、リーグ全体を震わせた。

■ 31歳、ヤニスのこれから

一つ懸念材料があるとすれば、年齢とケガの問題だ。31歳というヤニスの現在の年齢は、NBAのフィジカルな選手としてはピークを過ぎ始める時期とも言える。2シーズン連続でケガに悩まされており、今後の健康状態次第でこのトレードの評価は大きく変わる。

しかしヒートは「常に勝負を選ぶ球団」だ。リスクを承知で最強のカードを引きに行く——それがパット・ライリーのやり方だ。

路上で時計を売っていた少年が、NBAのコートで13年間歴史を作り、そして今また新天地へ。ヤニス・アデトクンボの物語は、まだ終わっていない。
