2012年4月28日。

デリック・ローズが、無意識のうちにNBA史を変えた日だ。

もしあの一瞬、着地が数センチ違っていたら。

ブルズは“王朝”になれていたかもしれない。

今回は実際のデータをもとに、その“もしも”を徹底的に考察する。

※本記事はNBA史上有数の“if”を扱う考察・エンターテインメント記事です。2012年以降の展開はすべて仮定に基づく予想であり、実際の出来事ではありません。

■なぜ今、この“もしも”を語る必要があるのか

デリック・ローズは2024年9月、静かに現役を退いた。

15シーズンで通算成績は17.4得点、5.2アシスト、3.2リバウンド。

シュート成績は46.2%、3P32.1%、FT83.4%。

数字だけ見れば「息の長い名脇役」のキャリアだ。

だが忘れてはいけない。

彼は史上最年少でMVPを獲得した男だった。

2010-11シーズン、わずか22歳でその栄誉を手にした。

本来なら、この数字はもっと大きくなっていたはずだった。

■悲劇の3分間｜2012年4月28日、フィラデルフィア戦

舞台は東地区1回戦Game1。

相手は第8シードのフィラデルフィア・セブンティシクサーズ。

ブルズはこの試合、103-91で危なげなく勝利していた。

ローズはこの日、23得点・9リバウンド・9アシストとMVPらしい活躍を見せていた。

試合終了まで残り1分20秒。

ブルズが12点リードしていた場面だった。

ローズはドライブから着地した瞬間、崩れ落ちた。

接触プレーではなかった。

検査の結果、左膝の前十字靭帯（ACL）断裂と判明した。

シーズンはそこで終わった。

そしてブルズの“王朝”への道も、そこで途切れた。

■もしあの瞬間がなかったら｜途切れたはずのない連勝街道

ここからが本題だ。

もしローズが健康なまま2012年のプレーオフを戦っていたら、何が起きていたか。

前提となる事実を整理する。

【実際のデータ】

2011-12シーズン成績（ロックアウト短縮66試合）：ブルズ50勝16敗（リーグ最高勝率タイ）

ローズの出場試合の成績：21.8得点・7.9アシスト・3.4リバウンド

東地区シード：1位

実際の1回戦結果：ローズ離脱後、76ersに2勝4敗で敗退（歴史的アップセット）

その年のNBAチャンピオン：マイアミ・ヒート（対オクラホマシティ・サンダー）

ブルズはリーグ最高勝率を持つチームだった。

ローズを欠いてなお、76ersを苦しめて2勝は挙げている。

もしローズが最後まで戦っていたら、この1回戦負けはまず起こらなかった。

■“もしも”の2012年プレーオフ｜予想されるブルズの進撃

ここから先は仮定に基づく予想である。

実際の対戦成績・チーム力を踏まえたシミュレーションだ。

1回戦：ブルズが76ersを4勝1敗程度で突破。

カンファレンス準決勝：ボストン・セルティックスと対戦、4勝2敗で突破と予想。

カンファレンス決勝：マイアミ・ヒート（レブロン擁する当時の絶対王者）と激突。ここが最大の山場。

NBAファイナル：仮にヒートを突破できていれば、オクラホマシティ・サンダー（デュラント・ウェストブルック）との“若きスター対決”が実現していた可能性が高い。

ここが最大の分岐点だ。

2011-12シーズン、ブルズはヒートとのレギュラーシーズン対戦で接戦を演じている。

ホームコートアドバンテージも1位シードのブルズ側にあった。

フルメンバーのブルズなら、ヒートとの7試合シリーズは十分に現実的だった。

■もし優勝していたら｜個人成績・受賞の“もしも”予想

実際のキャリアと、“もしも”のキャリアを比較する。

【個人成績・受賞比較】

MVP受賞回数：実際1回 → もしも2〜3回

オールNBAファーストチーム：実際1回 → もしも3〜4回

オールスター選出：実際3回 → もしも7〜8回

NBAチャンピオンシップ：実際0回 → もしも1〜2回

ファイナルMVP：実際なし → もしも可能性あり

キャリア平均得点：実際17.4点 → もしも23〜25点前後

殿堂入り（Hall of Fame）：実際微妙なライン → もしもほぼ確実

もっとも重要なポイントはここだ。

ローズは“素材”としてはリーグ最高峰だった。

爆発的なスピード、フィニッシュ力、勝負強さ。

故障さえなければ、カリー世代以前の“最強ポイントガード”として歴史に名を残していた可能性が高い。

■"もしも"の予想スタッツ｜シーズン別に見る成長カーブ

ここでは実際の負傷前ペース（23.5得点ペース・7.9アシスト）と、同世代スターの成長曲線を参考に、シーズンごとの"もしも"成績を予想する。

あくまで仮定に基づく予想値であり、実際の記録ではない。

2011-12シーズン：23.5得点 / 8.1アシスト / 3.6リバウンド ── 離脱なくプレーオフを完走。カンファレンスファイナル進出

2012-13シーズン：25.2得点 / 7.8アシスト / 3.9リバウンド ── 2年連続50勝ペース。MVP最終候補入り

2013-14シーズン：24.8得点 / 7.5アシスト / 4.0リバウンド ── ノアのDPOY獲得と共にブルズが優勝候補の一角に

2014-15シーズン：23.1得点 / 7.0アシスト / 3.8リバウンド ── 経験を積んだコアがファイナル進出圏内に到達

2015-16シーズン：21.5得点 / 6.6アシスト / 3.5リバウンド ── ベテランの域でも中心選手として君臨

この成長カーブが実現していれば、キャリア平均は23〜25点前後に到達していた可能性が高い。

実際のキャリア平均（17.4点）とは大きな差になる。

■もしもチームメイトはどうなっていたか｜ノア・デング・ブーザー・バトラーの運命

"もしも"の影響を受けるのはローズ本人だけではない。

当時のブルズを支えた主力たちの運命も変わっていた可能性が高い。

【ジョアキム・ノア】

実際に2013-14シーズンにDPOY（最優秀守備選手）を獲得したノア。

ローズが健在なら、より注目度の高いチームの守備の要として、さらに早い段階でオールスター級の評価を得ていた可能性がある。

【ルオル・デング】

実際には2014年1月、再建期のブルズからキャバリアーズへトレードされた。

だがローズ健在で優勝争いを続けるブルズなら、主力として引き続き重用され、トレードには出されなかった可能性が高い。

【カルロス・ブーザー】

実際には2014年、契約整理のためストレッチ条項で放出された。

チームが優勝争いを続けていれば、主力パワーフォワードとしてもう数シーズン長く在籍していた可能性がある。

【ジミー・バトラー】

当時はまだ出場機会の少ない若手だったバトラー。

実際の出世のきっかけは、ローズやデングの離脱で生まれた出場機会だった。

もしローズが健在で主力が固定されていたら、バトラーの台頭はもっと遅れていた可能性がある。

それでも彼の実力を考えれば、いずれ主力に食い込んでいたと考えるのが自然だ。

■ブルズ王朝は生まれたか｜NBA勢力図への影響

もしブルズが2012年か2013年に優勝していたら、NBA史はどう変わっていたか。

まず、ヒートの“スリーピート”（3連覇）挑戦が崩れていた可能性がある。

実際のヒートは2012年・2013年と連覇しているが、その一角をブルズが崩していたかもしれない。

さらに、ローズが健康を維持しブルズが常勝軍団になれば、フリーエージェント市場での主力選手の残留判断も変わってくる。

2015年のトレードでニックスへ放出される、という展開自体が起きなかった可能性も高い。

つまり“もしも”の世界線では、ブルズは2010年代のNBAを代表する強豪であり続けた可能性が高いのだ。

■関連記事・関連ポスト｜"もしも"を考察した実際の記事とポスト

この「もしもローズが怪我しなかったら」というテーマは、実際に海外メディアやファンの間でもたびたび語られてきた。以下は実在する関連記事とポスト（すべて英語のため、日本語要約・訳を添えている）。

【ESPN】How great would Derrick Rose have been if he never got hurt?

筆者はESPNの分析記者ケビン・ペルトン。独自の選手評価システムを使い、ローズと能力が近い同世代の選手10人（コービー・ブライアント、アレン・アイバーソン、ドウェイン・ウェイド、ラッセル・ウエストブルックなど）を抽出し、その後のキャリアを比較している。2010-11シーズンのローズはリーグ最強とまでは言えなかったが、トップ10級の実力は十分にあったと分析。中でも興味深いのはウエストブルックとの比較で、ケガをする前のローズとほぼ同水準の成績を残していたウエストブルックが、その後MVPまで登り詰めたことは、ローズの潜在能力の高さを裏付けているとしている。一方でギルバート・アリーナスのように、ヒザの手術をきっかけに一気に力を落とした前例もあり、ローズが同じ運命をたどった可能性も指摘している。記事は「ローズはNBA史上、MVPを獲得しながら殿堂入りできない最初の選手になる可能性が高い」と結んでいる。

https://www.espn.com/nba/story/_/id/21542402/how-great-derrick-rose-he-never-got-hurt-nba

【Bleacher Report】Imagining Derrick Rose's NBA Career If He Never Got Injured

2024年のローズ引退にあわせて掲載された特集記事。もしケガがなければ、という視点で7つの角度から検証している。当時のブルズは62勝20敗でリーグ最高勝率を記録し、ローズ・ブーザー・デング・ノアという主力4人のうち3人が20代前半という若く強力な布陣だったとし、ケガさえなければ優勝争いの常連になっていた可能性を指摘。実際のキャリアはオールNBA1回・オールスター3回にとどまったが、健康であればさらに多くの受賞歴を積んでいたはずだとしている。また2011年から2018年にかけてレブロン・ジェームズが8年連続でカンファレンスファイナルに進出しているが、健全なブルズであればその一角を崩せていた可能性にも言及。ローズの22歳までの通算成績は歴代でも15人しか上回れない水準だったとしたうえで、現状の殿堂入り確率はわずか10.5%にとどまると紹介し、ビル・ウォルトンやグラント・ヒルらと並ぶ"もしも"クラブの一員として、ローズを惜しむかたちで締めくくっている。

https://bleacherreport.com/articles/10136878-imagining-derrick-roses-nba-career-if-he-never-got-injured

【CHGO Ranks】What If Derrick Rose Never Got Hurt? Alternate Bulls Timeline

ブルズの現地メディアCHGO Sportsによる企画記事。AIシミュレーションを使い、ローズが健康なまま戦った場合のブルズの"もしも"のタイムラインを検証する内容。有料会員限定記事のため詳細は非公開だが、「もしローズが怪我をしていなければ、ブルズを優勝に導けていたか」という問いを軸に、シカゴスポーツ史上屈指の"if"として位置づけている。

https://allchgo.com/chgo-ranks-bulls-what-if-derrick-rose-never-got-hurt/

実際に投稿されたポストも紹介する。

日本語訳：グレッグ・オデンは2007年ドラフトでケビン・デュラントを差し置いて全体1位指名を受けたが、度重なる膝の手術でわずか105試合の出場にとどまった。デリック・ローズはMVP獲得の翌年、2012年プレーオフでACLを断裂し、あの爆発的なプレーレベルには二度と戻れなかった。史上最も"きつい"ifの2人だ。

■まとめ｜たった1回の着地が変えたもの

デリック・ローズの物語は、NBA史における最大の“if”のひとつだ。

接触のない、わずか一瞬の着地。

それだけで、1人のスーパースターのキャリアの方向性が完全に変わった。

実際の彼は、15年間戦い抜いた立派なキャリアを残した。

だが“もしも”の世界線では、複数回のMVP、複数回の優勝、そして殿堂入りが視野に入っていた可能性が高い。

この考察が示すのは、彼への同情だけではない。

1回の怪我が、いかにNBAの勢力図全体を変えてしまうかという事実そのものだ。

もしあなたが2012年4月28日に戻れるなら、何を変えたいだろうか。
